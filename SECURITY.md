# Security and sensitive-data policy

Do not report credentials, patient information, sample-identifying metadata or private server paths through a public issue. Contact the repository owner privately for security-sensitive reports.

The workflow executes configured external tools and an administrator-supplied APA-B command template. Only trusted administrators should modify shared project configurations, modulefiles, environments, reference manifests or the PolyAseqTrap adapter. Shared installations must be read-only to ordinary users.
