# Tracks and outputs

All BigWigs are transcript-strand-specific. Transcript-minus values are negative only for display; raw matrices, denominators and statistical calculations remain unsigned.

The C0-C5 labels below are workflow-specific count universes. Read [C0-C5 data stages](data_stages.md) before interpreting the tables if these labels are unfamiliar.

| Family | Signal | CPM denominator | Extra normalization |
|---|---|---|---|
| `all_reads` | C0 aligned blocks | C0 | none |
| `exact_ends` | C1 one-base ends | C1 | none |
| `filtered_ends` | C2 one-base ends | C2 | DESeq2 and robust CPM |
| `rejected_ends` | C2R one-base ends | C1 | none |
| `active_pas` | all C3 counts at summits | assigned C3 | DESeq2 and robust CPM |

Raw scale is 1. CPM is `1e6/N_family`. DESeq2 scale is `1/size_factor` using genome-global C4 `poscounts` factors. Robust CPM is `1e6/(size_factor × G)`, where `G` is the geometric mean of complete-C4 column sums. The R implementation verifies this matrix against `DESeq2::fpm(dds, robust=TRUE)`.

`09_tracks/track_normalization.tsv` records sample, genome, family, normalization, denominator, scale and count universe. BigWig is generated by default; `RETAIN_BEDGRAPH=true` preserves bedGraphs too. `GENERATE_BIGWIGS=false` is valid only when bedGraph retention is enabled.

The report stage automatically inventories and describes every generated BigWig:

| Output | Purpose |
|---|---|
| `10_reports/bigwig_collections.txt` | One textual column: collection header, then one BigWig filename per line |
| `10_reports/ucsc_track_descriptors/<family>__<normalization>.txt` | One-line UCSC custom-track definitions for one collection |
| `10_reports/ucsc_track_descriptors/UCSC_bigWig_tracks.oneline.txt` | All collection descriptors in one file, separated by a one-line group description |
| `10_reports/UCSC_trackDb.txt` | Compatibility combined descriptor file |
| `10_reports/IGV_session.xml` | IGV resource list for every generated BigWig |

Each collection receives a distinct RGB color. A transcript-minus descriptor adds `negateValues=on` by default because the corresponding BigWig stores negative values; UCSC then displays its magnitude above zero. Set `UCSC_NEGATE_MINUS_TRACKS=false` to retain the mirrored negative display. `UCSC_VIEW_LIMITS` defaults to `0:12`.

For directly usable UCSC URLs, configure a plain public prefix such as:

```bash
UCSC_BIGDATA_URL_PREFIX="http://150.254.121.240/Kartik/mouseQuantseq"
```

When this prefix is set, each `bigDataUrl` is the prefix plus the BigWig basename, matching a flat web-directory copy. If the prefix is empty, descriptors retain relative `09_tracks/<family>/<normalization>/...` paths and can be edited later. Never paste the Markdown form `[http://...](http://...)` into `config.conf`; validation rejects it.

By default, raw/CPM `all_reads` tracks start for a sample as soon as its final C0 BAM is published during the sample-merge phase. The workflow reserves the configured maximum merge CPU/RAM and uses only the remaining global budget for overlapping track workers. If no worker fits, publication is deferred automatically to the dedicated `c0_tracks` stage. The dedicated stage collects the per-sample outputs and writes `09_tracks/track_normalization.c0.tsv`; it does not regenerate samples with valid receipts. Each sample extracts one plus and one minus BAM and reuses them for both normalizations. `tracks_ends` later generates the enabled C1/C2/C2R/C3 families. `09_tracks/track_normalization.tsv` combines both stages. This checkpoint overlaps tracks with merging, not with STAR alignment.

If one strand has no signal for a sample/family, its retained bedGraph is empty. For BigWig conversion only, the workflow uses a temporary whole-contig zero-valued sentinel and then deletes it, yielding a valid zero-signal BigWig without inventing a count.

The numbered directories and their `run_receipt.json` files are stable module boundaries. Per-sample and per-contrast receipts live below `.receipts`; timing JSON lives in `.checkpoints/timings`. `00_metadata` contains resolved configuration, samples, lanes, contrasts, warnings and resource ceilings.

Final deliverables preserved by default include C0 sample BAMs, C1/C1S/C2/C2R tables, pooled discovery signal, active-PAS catalog, C3/C4/C5 matrices, DGE/APA statistics, BigWigs, reports and provenance. See the cleanup section in the main README for dispensable files.
